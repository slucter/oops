# Peta Repo

> Belum diisi. Jalankan `/peta` untuk membangunnya dari kode yang ada.

File ini adalah dokumen terpenting di harness. Dia yang membuat AI agent mana
pun — model apa pun, vendor apa pun — langsung paham bentuk projek ini tanpa
harus membaca ratusan file.

Isinya (lihat `.agent/skills/peta.md` untuk cetakan lengkap):

- Projek ini apa, untuk siapa
- Tumpukan teknologi
- Struktur folder beserta keterangannya
- Titik masuk
- Alur utama, ditelusuri dari masuk sampai keluar
- Model data
- Perintah untuk menjalankan, menguji, membangun, men-deploy
- **Aturan tak tertulis** — pola yang berlaku di kode tapi tidak terdokumentasi
- **Area rawan** — bagian yang mudah rusak dan kenapa
