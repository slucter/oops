# Catatan Keputusan Arsitektur (ADR)

Folder ini menyimpan **alasan** di balik keputusan arsitektur — hal yang tidak
terbaca dari kode.

Masalah yang diselesaikannya: agent di session berikutnya melihat keputusan lama
yang tampak aneh, lalu "memperbaikinya" — padahal keputusan itu punya alasan
yang kuat.

Penamaan: `NNNN-judul-ringkas.md`, nomor urut empat digit.

Tulis dengan skill `/keputusan`. Cetakannya ada di
`.agent/templates/adr.md`.
